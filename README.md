# Твой

Статический сайт продуктового магазина «Твой» в Поповке.

## Сборка

Требуется Node.js 22 или новее. Production-зависимостей нет.

```bash
npm run build
```

Сборка проверяет обе страницы (`index.html` и `produkty.html`): баланс HTML, уникальность идентификаторов, якоря, `aria-controls`, JavaScript, JSON-LD, CSS и наличие локальных ресурсов в deploy. Проверенные файлы копируются в `dist/` с проверкой SHA-256. Большие исходные фотографии остаются в Git; сайт использует responsive WebP и JPEG.

## Оформление и поведение

- `premium.css` — общие стили обеих страниц, красные акценты, адаптивная сетка.
- `catalog.css` — стили страницы ассортимента.
- `premium.js` — меню с управлением фокусом, статус работы по московскому времени, Wi-Fi и загрузка карты только по нажатию.
- Текст и изображения доступны сразу, без ожидания анимации. Параллакс и обработчики движения указателя удалены.
- Без JavaScript доступны навигация, отзывы, FAQ и ссылка на карту. Учтены `prefers-reduced-motion`, клавиатура и безопасная область экрана телефона.

## Проверка интерфейса

После правок проверить обе страницы на ширинах 320, 390, 768, 1024 и 1440 px. Проверить меню (Tab, Shift+Tab, Escape, переход к разделу), раскрытие FAQ и Wi-Fi, копирование пароля, отложенную загрузку карты, ссылки на телефон и отсутствие горизонтального скролла. Отдельно проверить мобильную версию с отключённым JavaScript.

## Netlify

`netlify.toml` задаёт `npm run build`, каталог `dist` и Node.js 22. Push в production-ветку запускает публикацию, если репозиторий подключён к Netlify.
